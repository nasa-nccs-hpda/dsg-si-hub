# ILAB Agentic AI

ILAB Agentic AI collects project context, curated references, lightweight examples, and reusable agent resources for ILAB teams. Detailed experiments and pipelines can live in each team's project repository.

## Start here

- [Projects](projects/README.md): find the IMVI and PACE-VCF entry points.
- [Contributing](CONTRIBUTING.md): placement, lifecycle, standards, and review checks.
- [Contribution tutorial](docs/Tutorial-Adding-Information-to-the-Repo.md): worked examples for saving useful agent context.
- [Agent instructions](AGENTS.md): behavior required of agents working here.
- [Documentation](docs/README.md): repository guidance and platform setup guides.
- [Glossary](GLOSSARY.md): shared repository terminology.
