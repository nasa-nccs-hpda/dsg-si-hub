# ILAB Agentic SI

ILAB Agentic SI collects project context, curated references, lightweight examples, and reusable agent resources for ILAB teams. Detailed experiments and pipelines can live in each team's project repository.

## Start here

This README is the main index for project resources, contribution guidance, and setup instructions. Use the locations and guide links below to find files in the repository.

If you are using Codex or Claude Code for the first time, or are just looking to get these to work through NASA, follow the [NMC SI Hub setup guide](docs/nmc/nmc_si_hub.md). It walks you through requesting NASA access, installing either tool, connecting it to Mission SI Hub, and starting your first session.

- [Projects](projects/README.md): find the Nexus and PACE-VCF entry points.
- [Contributing](CONTRIBUTING.md): placement, lifecycle, standards, and review checks.
- [Contribution tutorial](docs/Tutorial-Adding-Information-to-the-Repo.md): worked examples for saving useful agent context.
- [Agent instructions](AGENTS.md): behavior required of agents working here.
