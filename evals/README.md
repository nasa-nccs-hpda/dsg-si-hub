# Evaluations

Evaluations provide evidence that skills, agents, and project workflows behave as intended.

Start with the [evaluation template](../templates/evaluation/README.md). Create subareas when evaluation cases need them, following the [on-demand structure plan](../docs/repository-improvement-plan.md#on-demand-structure).

Each evaluation should identify the target, input or scenario, expected properties, environment, and last verified date. Prefer checking observable outcomes over matching exact prose. Use synthetic or approved test data.
