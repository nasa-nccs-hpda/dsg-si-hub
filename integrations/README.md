# Integrations

Integrations document how agents and contributors use external platforms, services, and execution environments. Store configuration guidance and safe operational procedures here; never store credentials.

- [NASA Mantle](nasa-mantle/README.md): access and client configuration

The existing [NASA Mantle guide](../docs/NASA-Mantle-LLM-Resources.md) remains the current Mantle reference.

Create other integration areas when real guidance needs them; possible categories are listed in the [on-demand structure plan](../docs/repository-improvement-plan.md#on-demand-structure).
