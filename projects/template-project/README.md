## Contributing

Create the following directories only when adding content that needs them. See the repository's [contribution policy](../../CONTRIBUTING.md) for placement and lifecycle rules.

- Put project context in `knowledge/`.
- Put repeatable project-only procedures in `skills/`.
- Put safe examples in `examples/`.
- Put acceptance cases in `evals/`.
- Put project-only prompts in `prompts/` and agent configurations in `agents/`.
- Promote reusable material into shared repository areas when another project needs it.
