# Projects

Projects are the primary entry point for teams. Each project owns its working knowledge, prompts, examples, evaluations, and project-specific agent capabilities.

## Create a project

Start from the [project template](../templates/project/) and follow the [contribution workflow](../CONTRIBUTING.md#basic-workflow). The [contribution lifecycle](../CONTRIBUTING.md#contribution-lifecycle) explains when project material belongs in shared areas; the [tutorial](../docs/Tutorial-Adding-Information-to-the-Repo.md#start-a-project-from-the-template) shows a worked example.
